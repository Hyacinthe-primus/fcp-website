Installation

Download the latest FileConverterPro_Setup_v1.0.8.exe from the Releases page and run it.

The installer:

  • Runs without administrator rights
  • Supports English, French, Italian, Russian and Turkish during setup
  • Targets 64-bit Windows 10 / 11 only
  • Optionally creates a Desktop shortcut
  • Optionally associates .fcproj project files with the app
  • Offers to add a Windows Defender exclusion for the install folder

PowerShell one-liner (silent install)

$f="$env:TEMP\fcp.exe"; Invoke-WebRequest "https://github.com/Hyacinthe-primus/File-Converter-Pro/releases/latest/download/FileConverterPro_Setup_v1.0.8.exe" -OutFile $f; Start-Process $f "/SILENT" -Wait; Remove-Item $f

Portable version

Download the .zip from the Releases page, extract anywhere, and run FCP.exe. All settings, history, and achievements are stored in the same folder, you can move the folder and everything moves with it.

The portable version does not create automatic file associations for .fcproj files. Open projects via File → Open Project inside the app.

PowerShell one-liner (portable)

$z="$env:TEMP\fcp.zip"; $d="$env:USERPROFILE\Downloads\FileConverterPro"; Invoke-WebRequest "https://github.com/Hyacinthe-primus/File-Converter-Pro/releases/latest/download/File_Converter_Pro_v1.0.8.zip" -OutFile $z; Expand-Archive $z -DestinationPath $d -Force; Remove-Item $z; Start-Process explorer.exe $d

Optional tools

FCP works on a clean machine. Install any of the following and it will detect them automatically for higher-quality output, no configuration needed.

ToolWhat it unlocks
FFmpegRequired for audio and video conversions and media optimization.
Microsoft OfficePixel-perfect DOCX / XLSX / PPTX and OpenDocument → PDF via COM automation.
LibreOfficeHigh-quality Office/OpenDocument conversions when Office isn't installed.
PandocPrimary EPUB → PDF rendering; MiKTeX enables its LaTeX pipeline for the best typographic output.
MiKTeXWorks with Pandoc for high-quality EPUB → PDF typesetting.
wkhtmltopdfBest HTML → PDF rendering — full CSS, fonts, local images.
GhostscriptBetter PDF optimization and compression for smaller output files.
TesseractOCR engine used by scanlayer to create searchable PDFs. Without it, images still convert to plain PDFs.
ImageMagickRequired for image → PSD output.

Windows Defender & antivirus

Adding the install folder to Defender exclusions is strongly recommended. The installer offers to do this automatically. For the portable version:

Add-MpPreference -ExclusionPath "C:\Your\Folder\FCP"

If you get an "application control policy blocked this file" error, run this in an Administrator PowerShell, replacing the path with your actual install folder:

Get-ChildItem -Path "C:\Your\Folder\FCP" -Recurse | Unblock-File
Adding a Defender exclusion and running Unblock-File are two separate mechanisms. Both may be needed if you downloaded the portable zip.

Languages

FCP ships with English, French, Turkish, Italian, Russian and Simplified Chinese. To add another language, create a .lang file (UTF-8 JSON) and place it in the languages/ folder (_internal/languages/ in the installed build, or src/languages/ from source). It appears in Settings on the next launch.

See CONTRIBUTING.md for a step-by-step guide.

Custom themes

FCP includes Dark and Light themes and supports community .fctheme packs. Install one from Settings → Themes → Install a theme (.fctheme), or browse the FCP Themes repository.

To build or submit a theme, follow the repository's CONTRIBUTING.md; the Themes wiki page is the short version. Imported themes live in _internal/styles/custom_themes/ in the installed build, or src/styles/custom_themes/ from source.

Clone & install

git clone https://github.com/Hyacinthe-primus/File-Converter-Pro.git cd File-Converter-Pro pip install -r requirements.txt python src/main.py

Requires Python 3.10 or 3.13.

Project structure

See the Directory Tree on the project wiki for the current source layout, packaging files, tests, and runtime-generated files.

Building the exe

The project uses PyInstaller for the executable and Inno Setup for the installer. See the For Developers wiki page for the full build guide. The main build auto-detects UPX from PATH; `build_all.ps1` also creates the portable ZIP and SHA-256 checksums in Output/ using 7-Zip. Be careful with UPX and Qt DLLs, as improper usage can corrupt them.

Contributing

Contributions are welcome: Translations, Bug fixes, or larger features. Read CONTRIBUTING.md first. For complex changes (Linux port, new format category), open an issue before starting work.

Known limitations

AreaDetails
Windows onlyCOM automation, registry-based dark mode detection, and PyInstaller packaging are Windows-first. macOS / Linux planned.
Build size~225 MB compiled – inherent to Python + PySide6 + Matplotlib.
PDF → DOCX qualityDepends on source PDF. Scanned PDFs with no text layer are only partially recoverable.
HEIC outputHEIC/HEIF input is supported, but HEIC output requires an extra plugin and is unavailable in the bundled build.
DNG outputDNG/RAW files are supported as inputs; DNG output requires a Pillow DNG writer and is unavailable in the bundled build.
OCRRequires Tesseract and its language data. Accuracy depends on scan quality and the installed language packs. Orientation can be automatic or a custom angle in degrees.
No cloud / syncHistory and settings are local only – no account or multi-device sync. The portable build keeps everything in its folder.
Solo developmentProgression depends on availability outside of studies.
