What you get

Everything, out of the box

A file converter that feels like a real product, not a barebones utility somebody abandoned in 2014.

All-in-One Conversion

Documents, images, audio, video, all handled from one window. No juggling five different tools or ten browser tabs. Batch mode works across every category; drop as many files as you need.

  • Documents: TXT, RTF, ODT, ODS, ODP, CSV, JSON, XLSX, PPTX, HTML, Markdown, PDF, EPUB
  • Images: broad input support with PNG, JPEG, AVIF, ICO, SVG, PSD, J2K and more
  • OCR: images and scans become searchable PDFs with optional custom orientation
  • Audio & Video with a separately installed FFmpeg
  • Batch conversion targets PDF, DOCX, and PNG with per-file error reporting

100% Offline & Private

Your files never leave your machine. No telemetry, no upload calls, no internet requirement of any kind during conversions. Everything runs locally using the engines already on your system.

  • Zero network activity during conversion
  • No account, no registration
  • Encrypted local settings (Fernet)
  • Optional backup copy before conversion
  • SQLite-backed local history only
  • Temporary files cleaned up automatically

Multi-Engine Fallback

FCP chains multiple conversion engines automatically. It detects what's installed: Microsoft Office, LibreOffice, Pandoc, MiKTeX, wkhtmltopdf and picks the best one available. No configuration needed.

  • Works on a clean machine with zero extras installed
  • Automatically upgrades quality when you install optional tools
  • PPTX→PDF: PowerPoint COM › LibreOffice CLI › python-pptx+ReportLab
  • ODT/ODS/ODP→Office: Office COM › LibreOffice › native zip/XML fallback
  • ODT/ODS/ODP→PDF: Office COM › LibreOffice
  • HTML→PDF: wkhtmltopdf › WeasyPrint › ReportLab

Statistics Dashboard

A full Matplotlib-powered analytics panel with animated charts showing your conversion history at a glance. Filter by date and export the dashboard to CSV or JSON; the separate History window also supports Print to PDF and JSON export.

  • Animated bar chart – conversions per day
  • Animated filled line chart – data volume over time
  • Animated donut chart – operation type breakdown
  • Dashboard CSV/JSON export, with Print to PDF and JSON export in History

Achievements & Rank Progression

A complete gamification system backed by SQLite. Achievements unlock based on conversion counts, format diversity, streaks, and special events. Can be disabled in Settings if it's not your thing.

  • Animated pop-ups when an achievement is earned
  • Rank-up celebration dialogs at milestone ranks
  • Full achievements panel to browse between locked & unlocked states
  • Entirely optional, you can disable from Settings

Windows Context Menu Integration

Right-click any supported file in File Explorer and you'll see a Convert with FCP sub-menu listing only the relevant conversions for that file type. A lightweight Quick Convert window opens, runs the conversion, and closes automatically.

  • Works on all supported formats
  • Each file type shows only its relevant conversions
  • Quick Convert closes automatically after success
  • Enabled during install and can be unchecked

Automation & Frequent-Config Templates

Point FCP at a folder or give it a schedule and it keeps converting in the background. Configurations you reuse often can become automatic templates, so the setup is already there next time.

  • Watch folders convert new files automatically
  • Scheduled tasks run at an interval or a specific time
  • OCR rules produce searchable PDFs in the background
  • Configs used three times become [Auto] templates

Polished UI, Custom Themes & Special Events

Automatic dark/light mode reading directly from the Windows registry. Go further with community .fctheme packs: install one from Settings, and the whole app restyles instantly. Animated splash screen and date-aware special events are still included.

  • Glassmorphism stat cards and fluid transitions
  • Themeable dialogs, splash screen and Quick Convert window
  • Searchable Quick Launch picker with keyboard navigation
  • Browse and install themes from the FCP Themes gallery
  • Single-instance: a second launch focuses the running window
  • Native Windows toast notifications on conversion finish
  • Drag files directly onto the .exe to pre-load them
